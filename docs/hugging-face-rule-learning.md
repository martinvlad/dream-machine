# Hugging Face background rule learning

Experimental adapter for PR168. It generates a bounded rule from public or synthetic training observations, tests training consistency locally and asks for repair at most twice (three total calls). It keeps the deterministic proposer as fallback. It never runs arbitrary generated code, exposes hidden evaluation data or promotes a rule. This is bounded proposal refinement, not model weight training or demonstrated recursive self improvement.

Build with `npm run build -w @dream-machine/compile`. Run `node --test scripts/hf-rule-learning.test.mjs`. With an existing authorized HF_TOKEN secret binding, run `node scripts/run-hf-rule-learning.mjs observations.json config.json`.

The observation file is an array of `{state:{x:1},action:2,nextState:{x:3}}` transitions. Configuration requires model (`organization/model`), an explicit provider, maxCostUsd, inputUsdPerMillion and outputUsdPerMillion verified from current provider pricing. Optional maxCalls defaults to 2 (maximum 3), maxOutputTokens 512 (maximum 2048) and timeoutMs 15000 (maximum 60000). No price or model availability is assumed by the implementation. Test fixtures use illustrative prices, never a live quote.

Spending reservation uses input payload bytes plus a 4096 token protocol allowance and requested maximum output tokens. This is a conservative estimate, not a billing guarantee. Use a provider/account spending limit as the authoritative cap, verify tokenizer and provider billing semantics before paid use, and reconcile billed usage externally. Failed requests retain their reservation. No retries after transport/validation failures. No new dependencies or endpoint provisioning.

Threat boundaries: the token goes only to the fixed HTTPS Hugging Face router; redirects fail. Error details are suppressed. Response bodies are bounded at 64 KiB and requests have an abort deadline. Candidate schema and safe integer operations are independently validated by the existing interpreter. Caller must classify observations as permitted for provider disclosure. Training receipts are not hidden evaluation evidence. Hosted model regeneration is not guaranteed deterministic; capture candidate artifacts and replay locally.

Pass returned candidates into the independent MetaHarness evaluator from PR394, using evaluator-owned untouched tasks; signed promotion remains with Autogenous PR19. Do not feed final holdout failures back into this learning loop. The two identical training arrays used internally are solely a training consistency check, not two independent datasets. Final acceptance remains a 20 percentage point gain on two of three distinct tasks, no family regression, 25 percent fewer environment interactions, independent probes and exact replay. Count inference tokens and total cost separately.

Validation on 2026-10-11: ten mocked transport tests cover proposal, repair, budget exhaustion, missing credentials, unsupported operations, rate limiting, oversized/malformed output, routing and timeout. Live inference is blocked because this workspace has no HF_TOKEN binding. No measured model quality, spend or latency claim is made.
